脉冲 Pulse — Windows 桌面版与网页版

1. 将整个文件夹解压到任意位置，双击 Pulse.exe。无需安装 Node.js、pnpm 或 Python。
2. 双击“打开网页版.cmd”，或在软件菜单“软件 → 在浏览器打开网页版”打开浏览器。
   两个界面共用同一后台和虚拟账户；请保持桌面软件运行。网页版地址使用本机随机空闲端口，可在“帮助”菜单查看。
3. 再次双击只会切换到已运行的实例；关闭桌面窗口即退出软件和本地后台，浏览器随后显示离线。
4. 顶部“现货 / USDT 永续”可切换市场；两个市场都自动扫描，报价为各自最新成交价（last）。
   对比欧意时请使用同一合约与“最新价”，现货、永续、标记价和指数价可能不同。
   两个市场的账户、自动开关、持仓、回测与 CSV 独立；切换不停止另一市场，重置只作用当前市场。
   自动入场默认关闭；所有金额均为虚拟积分，无真实下单功能。
   永续按基础币等值做无杠杆模拟，未模拟资金费、保证金及强平；离线回放为独立合成样本。
5. 账户与配置保存在 %APPDATA%\PulseTradingDemo。菜单可直接打开目录或编辑 settings.env；配置保存后重启。
   更新软件只需替换程序文件夹。不要删除用户数据目录，账户不会随程序文件夹替换而丢失。
   现货保存在 trader.sqlite，永续保存在 trader.swap.sqlite；升级沿用旧现货账户。
   备份请先退出软件，再复制整个用户数据目录；重置当前市场的账户需在界面确认。
6. 公共行情需要网络但不需要 OKX 密钥；外部网络不可用时，可以打开离线合成样本回放。
   行情优先使用 WebSocket 实时推送，自动重连，默认每秒 REST 轮询兜底。界面显示交易所毫秒时间、报价年龄和来源。
   无新数据时不会伪造价格；报价过期会暂停该币种成交。5 分钟图表及策略信号仍只使用已收盘 K 线。
   AI 可选：在 settings.env 填写 OPENAI_API_KEY 与 OPENAI_MODEL。只有点击解读才调用，可能产生 API 费用。
7. 此包支持 Windows 10/11 x64，默认仅监听 127.0.0.1，不需要管理员权限，不对局域网或公网开放。
   本次本地构建未使用商业代码签名证书。若 Windows 拦截，请先核对 ZIP SHA256 和来源；不要关闭系统安全防护。
8. build-manifest.json 记录源码与文件校验值；ZIP 旁的 .sha256 文件用于校验整个发布包。

网页版源码的安装、开发与生产启动命令以及策略/风险/回测限制，见随包提供的 README.md。
图表使用 TradingView Lightweight Charts，内置归属标识保留；Electron/Chromium 许可证随程序提供。
